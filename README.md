# Anton-Trofimov.github.io

Personal portfolio and interactive AI project demonstrations by Anton Trofimov.

- `/` redirects to [my portfolio](https://github.com/Anton-Trofimov/applied-ai-portfolio).
- `/gov-agent/` contains the recorded Governed Agent Runtime demonstration. It runs in the browser without a live backend or model connection.

## Source and attribution

The demonstration is built from [Governed Agent Runtime](https://github.com/Anton-Trofimov/governed-agent-runtime), revision `c4ba6da3c552bd5b543e19777f6d90c54a976097`.
This repository contains static publication files. Development and reproduction instructions are in the source repository.
